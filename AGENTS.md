# AI Coding Agent Instructions

- Before every implementation, read both `docs/ProductVision.md` and
  `docs/ProjectStatus.md`. Treat `docs/ProjectStatus.md` as the authoritative
  reference for the application's current state.
- Updating `docs/ProjectStatus.md` is a mandatory deliverable at the end of
  every completed sprint. Record the sprint, release and version information,
  current features and architecture, open issues and technical debt, backlog,
  next planned sprint, and the `Last updated` date.
- Build mobile-first.
- Use English only.
- The official application name is `VinoCastello`. Use that exact spelling in
  documentation, UI text, prompts, architecture documents, and comments.
- Keep the UX simple.
- Treat the canonical Wine model as the single source of truth.
- Never duplicate business logic.
- Explain the root cause before fixing bugs.
- Run tests.
- Run the production build.
